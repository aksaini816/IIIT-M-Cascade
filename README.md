# TraceTrust — Decentralized Education Donation Tracking System (Frontend MVP)

Frontend-only hackathon MVP demonstrating transparent donation tracking workflows for underprivileged children's education.

## What is implemented

- React + TypeScript + Vite app with Tailwind CSS
- Responsive sidebar dashboard layout
- Working routes for:
  - Overview
  - Donations
  - Fund Tracking
  - Evidence Vault
  - Fraud Detection
  - Escrow Management
  - Audit Log
  - Project Information
- Seeded demo data with local state persistence in `localStorage`
- Reset Demo Data action
- Interactive filters, searches, modals/drawers, form validation, and simulated actions
- Recharts donation trend visualization

> **Important:** This is a frontend demonstration only. There is no backend, no authentication, no payment integration, and no deployed blockchain/smart-contract system.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (typically `http://localhost:5173`).
